# Sleeps to Llandudno

A live countdown to our summer holiday in Llandudno, Cape Town — 18 November.

Single static page (`index.html`), no build step. Deploy anywhere that serves
static files; on Vercel just import the repo and deploy with the default
settings.

The countdown targets midnight on 18 November, South African time (UTC+2),
and rolls over to next year's date once the holiday has passed.
